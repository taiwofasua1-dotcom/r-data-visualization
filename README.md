# R Data Visualization - Restaurant Tips

Data visualization in R using ggplot2 and dplyr.

Dataset: Public restaurant tips dataset (244 rows).

### Questions Answered
1. How does tip vary by day?
2. Does total bill predict tip?
3. Do lunch vs dinner tips differ?

### Skills Shown
- Data manipulation with dplyr
- Visualization with ggplot2
- Boxplots and scatter plots
